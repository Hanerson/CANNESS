The Cummin practice report records a target compiler assertion in dav_c220/kernel_operator_vec_cmpsel_impl.h: the selected overload expected a __ubuf__ half pointer. Treat the overload, argument and dtype combination as unsupported on that tested target until verified; do not conclude that every Select overload has the same restriction. Read the installed header with fetch_remote_file after configuring the precise toolchain readRoots, and use compile_only to test a minimal real kernel. Preserve the header SHA-256 returned by the fetch tool as evidence when recording a reproduced entry.
