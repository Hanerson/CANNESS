# CAN-208 `Gelu.md` 的文字推导把 tanh 的输入多乘了一倍

| 字段 | 值 |
|---|---|
| 类型 | 缺陷 |
| 优先级 | **P2** |
| 组件 | `plugin/knowledge_base/Gelu.md` |
| 首次发现 | 2026-11-27 只读评估 |
| 状态 | **fixed** |
| 标签 | `knowledge`, `gelu`, `accuracy` |
| 复核 | 2026-11-27。已用 x=1 核对错式与正确式 |

## 现象

笔记先给出正确的 tanh 近似：

`Gelu(x) = 0.5 * x * (1 + tanh(sqrt(2/pi) * (x + 0.044715 * x^3)))`

接着令 `y = 2 * sqrt(2/pi) * (x + 0.044715 * x^3)`，再写 `tanh(y) = 1 - 2 / (exp(2y) + 1)`，并用 `1 + tanh(y)` 组装 Gelu。这里的 `y` 已经是标准公式内层的 2 倍，文字路径得到的是 `tanh(2 * inner)`。

同文件的 AscendC 片段是对的。它计算 `y = 2 * inner`，然后 `2 - 2/(exp(y)+1)`，这等于 `1 + tanh(inner)`。

取 `x = 1`：按错误的文字组装，结果约为 0.965585；按正确公式和代码片段，结果约为 0.841192。

笔记标题仍写着测量时的 CANN 版本。这个历史工具链记录保留，中间公式单独改正。

## 证据

- `plugin/knowledge_base/Gelu.md` 第 7–16 行：正确公式，以及把 `tanh(y)` 当成 Gelu 组装步骤的文字。
- 同文件第 33–41 行：`Muls(..., 1.5957691216057308f)` 得到 `2*sqrt(2/pi)*...`，随后 `Exp`、`2 - 2/(exp+1)`。
- `x = 1` 时，错式约为 0.965585，正确公式与代码片段约为 0.841192。
- `plugin/src/knowledge-search.ts` 的 `searchKnowledge`：无结构化命中时回退到根笔记。`entries/` 下没有 Gelu 条目。

## 影响

照文字推导实现，`x = 1` 会得到约 0.965585，对不上约 0.841192 的 tanh 近似。照代码片段才能得到笔记开头的公式。知识库校验只查结构化条目的格式，管不到这篇笔记的公式。

## 期望

文字与代码描述同一个恒等式：`y = 2 * inner` 时，`1 + tanh(inner) = 2 - 2/(exp(y)+1)`。标题和正文里的历史工具链记录保留，并标明它对应哪一次测量。

## 复现

1. 取 `x = 1`，`inner = sqrt(2/pi) * (x + 0.044715 * x^3)`，`y = 2 * inner`。
2. 按第 14–16 行计算 `0.5 * x * (1 + tanh(y))`，得到约 0.965585。
3. 按代码片段计算 `0.5 * x * (2 - 2/(exp(y)+1))`，得到约 0.841192。
4. 后者等于标准公式。

## 建议修复

把第 14–16 行改成：

```text
y = 2 * sqrt(2/pi) * (x + 0.044715 * x^3)
1 + tanh(inner) = 2 - 2 / (exp(y) + 1)
Gelu(x) = 0.5 * x * (1 + tanh(inner))
```

保留笔记里的历史工具链记录。另给 `x = 1` 的数值例：错式约 0.965585，正确式约 0.841192。

## 验收标准

- 笔记中的文字公式与代码片段在 `x = 1` 上都给出约 0.841192。
- 笔记中不再把 `tanh(y) = 1 - 2 / (exp(2y) + 1)` 当作 Gelu 的组装步骤。
- 历史工具链记录仍在，并标明适用范围。

## 关联

CAN-207（检索回退规则）。

## 处置和验证

修正 GELU 的文字等价式，保留历史工具链记录。
